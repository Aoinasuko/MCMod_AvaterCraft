# NPC行動モデル v5 の学習データ

56特徴量の候補順位付け用データです。言語モデルの学習データではありません。

学習60,222件は、従来の合成データ48,000件、新しい地形・経路コストの合成データ12,000件、Neo実行ログから抽出した222件で構成します。検証7,500件、独立評価7,500件は学習と重複しない合成データです。自然地形の完走試験は学習に含めません。

`observed-actions.jsonl.gz` は、実際に選択・実行された操作の209成功・13失敗を保持します。未実行の候補の成否は不明のまま `mask=false` とし、成功と決めつけません。上位のacquire・仲間待ちへの失敗伝播、取消、対応する結果がない操作は教師ラベルから除きます。候補の特徴量、結果、元ログのSHA-256、行番号と操作IDを保存し、会話本文・認証情報は含めません。実ログの同じ試行を学習と評価へ分散させていません。

再生成・再学習はプロジェクト直下で実行します。

```powershell
python tools/train_npc_policy_v5.py --logs build/npc-neo-investigation-20261026 --initial build/npc-policy-v5/original-v4.bin
```

元JSONLがない場合も、同梱の `observed-actions.jsonl.gz` から同じ観測済みサンプルを読み込めます。従来データは `python tools/generate_npc_curriculum.py` で `TrainingData/npc-v4/` へ生成します。v5の初回は48入力のv4重みが必要で、`initial-policy.bin` に保存して以後も同じ初期値を使います。

既定の出力は `build/npc-policy-v5/action-policy.json` と `.bin` です。学習器は配布用のモデルを直接置き換えません。検証・独立評価で厳密な最適候補選択98%以上、緊急動作99.9%以上、実行不能候補の選択0件を満たしたものを採用します。補助指標として教師スコア差0.04以内の選択率も記録します。これらの数値はMinecraftの依頼完走率ではありません。

初期重み、全学習・検証・評価ファイルはローカル生成物としてGit対象外にし、実ログ由来の小さい圧縮データとmanifestを保持します。Python・NumPy・PyTorchは開発時だけ必要で、ゲームでの推論はJavaのみです。
