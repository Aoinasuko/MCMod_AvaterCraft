# NPC version 4 学習データ

`python tools/generate_npc_curriculum.py`で再生成します。原本は`tools/generate_npc_curriculum.py`にある138シナリオと日英テンプレートです。実プレイの会話・UUID・認証情報は使用していません。

- `train.jsonl.gz`：学習192,000組。各行に日本語・英語の指示、観察条件、想定計画、48特徴量×6候補、選択ラベルを保存。
- `validation.jsonl.gz`：検証12,000組。学習と異なる命令テンプレート・乱数を使用。
- `test.jsonl.gz`：独立評価12,000組。検証とも別の命令テンプレート・乱数を使用。
- `manifest.json`：件数・曖昧な例の件数・文面のユニーク数・圧縮ファイルのSHA-256。
- `initial-policy.bin`：実際に使用した初期重み。再学習時も同じファイルを用いることで重みの再現性を確認可能。

合計216,000組、432,000文です。同じ命令でも状況が異なる例を含み、文面のユニーク数とは異なります。状態付きの「あれ」「さっきの続き」「不足分」「いつもの場所」「トウヒ以外」と、参照先を特定できず確認が必要な例を対比させています。複数の候補が同じ教師効用になることがあります。

モデルが学習するのは構造化した行動候補の順位です。自然言語の解釈は接続中の指示理解AIが担当し、同梱の`instruction-examples.json`から関連例を最大3件参照します。学習精度を自然文の解釈率やMinecraft全攻略の成功率とは扱いません。未成熟作物・危険・権限などは実行時にも判定します。

圧縮データと初期重みは生成物としてGit対象外ですが、このフォルダに実ファイルを保存しています。ゲーム配布には行動モデルと少量の指示例だけを含め、学習データ一式は含めません。
