COMPANION

アバターと、
一緒に冒険する。

A companion for
your next adventure.

Companionを追加して、AIで動くアバターを仲間に。接続設定、召喚、モデルと性格の変更、作業の頼み方を案内します。

Add Companion to turn an avatar into an AI-controlled companion. Configure a connection, summon an NPC, choose a personality and give it tasks.

26.3-0.10.0Minecraft 26.3NeoForge 26.3.0.95Java 25Unity 2022.3
01 / PREPARE

LoaderとCompanionを導入する

Install Loader and Companion

bep_3davater_loader-26.3-0.10.0.jarとbep_3davater_companion-26.3-0.10.0.jarを、NPCを使うクライアントとサーバーのmods/へ配置します。Player Modelは、プレイヤーの外見も変える場合に追加します。

標準モデルtortobuはLoader、性格サンプルはCompanionに同梱しています。追加の.avcは表示する各クライアントのconfig/bep_3davater_loader/avatars/へ置きます。

Place bep_3davater_loader-26.3-0.10.0.jar and bep_3davater_companion-26.3-0.10.0.jar in mods/ on each client and server using NPCs. Add Player Model if you also want to change player appearances.

Loader includes tortobu; Companion includes its sample personality. Place additional .avc files in config/bep_3davater_loader/avatars/ on every client that displays them.

02 / AI CONNECTION

AIモデルへ接続する

Connect an AI model

  1. @（US配列は[の位置）で設定を開き、AIモデルタブを選びます。
  2. 「接続方法」をクリックして方式を切り替え、AIを有効にします。
  3. API方式では接続先URLとAPIキーを入力します。URLは通常/v1までで、/chat/completionsや/messagesは付けません。
  4. 通常モデルを一覧から選択で取得・検索・選択します。モデルIDを直接入力することもできます。
  5. 必要なら「計画用モデルID」を指定します。空欄なら通常モデルを使います。
  6. 設定を保存を押し、ワールドを開き直します。専用サーバーはサーバー側で設定を変更して再起動します。

APIキー・ローカルモデルの注意点

入力キーは伏せ字表示ですが、ホストのTOMLへは平文保存されます。キー入り設定ファイルを配布しないでください。環境変数名を指定した場合、そこに値があると入力キーより優先します。認証不要のローカルサーバーではキーと環境変数名を空欄にできます。会話・関数ツール呼び出し・JSON出力に対応するモデルを選んでください。MODはモデルを自動ダウンロード・起動しません。一覧取得に非対応のAPIではモデルIDを直接入力します。

Codex / ChatGPT OAuthの準備

AIを実行するホスト環境へCodex CLIを用意し、codex loginでログインしてください。codex login statusで確認できます。PATHから見つからない場合はタブの「Codex CLI」欄へ実行ファイルのパスを入力します。モデルIDが空欄ならCLIの既定を使います。確認したCLIは0.163.0です。

  1. Open settings with @ (the [ position on a US keyboard) and select AIモデル (AI Models).
  2. Click the connection-method button to cycle through methods and enable AI.
  3. For API connections, enter the base URL and API key. Normally the URL ends at /v1; do not append /chat/completions or /messages.
  4. Click 通常モデルを一覧から選択 to fetch, search and choose a normal model. You can also type the model ID directly.
  5. Optionally specify a planning model. Leave it blank to use the normal model.
  6. Click 設定を保存 (Save settings), then reopen the world. For a dedicated server, edit settings on the server host and restart it.

API keys and local models

Keys are masked in the UI but stored in plaintext in the host's TOML. Do not distribute a populated config. If the named environment variable contains a value, it takes precedence over the entered key. Leave both fields blank for local servers without authentication. Choose a model supporting conversation, function tools and JSON output. The mod does not download or start models automatically. Enter the model ID manually if the endpoint does not provide a model list.

Prepare Codex / ChatGPT OAuth

Install Codex CLI on the AI host and sign in with codex login. Check it with codex login status. If it is not on PATH, set the executable path in the Codex CLI field. A blank normal model ID uses the CLI default. The checked CLI version is 0.163.0.

03 / SUMMON

ソウルストーンでNPCを召喚する

Summon an NPC with a Soulstone

作業台で鉄インゴット4個（I）と金インゴット5個（G）を次の配置にすると、ソウルストーンを1個作れます。

IGIGGGIGI
  1. ソウルストーンを手に持ち、空きスペースのある地面へ使用します。
  2. 標準のtortobuが召喚されます。通常はストーンを1個消費します。
  3. 召喚したプレイヤーが所有者になります。既定の上限は1人3体です。

同梱の性格は、一人称「ぼく」でおっとりした仲間です。モデルと性格は召喚後に変更できます。

Craft one Soulstone using four iron ingots (I) and five gold ingots (G) in this arrangement:

IGIGGGIGI
  1. Hold the Soulstone and use it on ground with room for the NPC.
  2. The default tortobu is summoned. Normally one Soulstone is consumed.
  3. The summoning player becomes its owner. The default limit is three companions per player.

The bundled personality is gentle and laid-back and uses “ぼく” (boku) in Japanese. You can change its model and personality after summoning.

04 / CUSTOMIZE

モデルと性格を変更する

Change a companion's model and personality

  1. @からCompanionタブを開きます。自分が召喚しているNPCが一覧に表示されます。
  2. 変更したいNPCをクリックし、左のモデル一覧から外見を選びます。
  3. 右の性格ボタンでプリセットを切り替えるか、性格JSONを編集します。
  4. モデル・性格を保存で対象のNPCへ反映します。未読込のNPCは、読み込まれてから再試行してください。

独自の性格は、配布物のExamples/Personalities/tortobu.jsonをコピーして作れます。idとファイル名を一致させ、ホスト側のconfig/bep_3davater_companion/personalities/<id>.jsonへ置きます。1ファイル16KiB以下です。nameは名前、avatarはモデルID、instructionsは性格の説明、speakingStyleは口調です。

表情はLoaderで対象モデルのeat・hurtなどを設定します。食事・被ダメージの判定はCompanionが行います。

  1. Open Companion from the @ settings. The list shows NPCs you own.
  2. Click the target NPC and choose its appearance from the model list on the left.
  3. Use the personality button to cycle presets, or edit the personality JSON on the right.
  4. Click モデル・性格を保存 (Save model and personality). For an unloaded NPC, retry after it has loaded.

To create a custom personality, copy Examples/Personalities/tortobu.json from the release. Match the filename to its id and place it on the host in config/bep_3davater_companion/personalities/<id>.json. Keep each file at or below 16 KiB. name controls the name, avatar references the model ID, instructions describes the personality, and speakingStyle sets its manner of speech.

Configure eat, hurt and other expression keys for that model in Loader. Companion detects eating and damage events.

05 / PLAY TOGETHER

持ち物・会話・作業指示

Inventory, conversation and tasks

所有するNPCを右クリックすると、右端のアイコンから4つのメニューを選べます。アイコンにカーソルを重ねると説明が表示されます。

メニュー操作
持ち物上にNPC、下にプレイヤーの持ち物。クリック・Shiftクリックで受け渡し。防具・主手・副手も設定。
性格・外見性格JSON・モデル・プリセットを編集し「保存・実行」。
作業指示指示を入力し「保存・実行」。「作業停止」で停止。「追従: ON/OFF」で待機中の追従を切り替え。
記録会話・指示・作業の結果を閲覧。「過去の記録」で以前の履歴。

最初は、範囲と数を具体的に

  • 「原木を16個集めて、このチェストに入れて」
  • 「ついてきて」「ここで待って」
  • 「座標100,65,100から104,67,104までの石を掘って。床はY64に残して」

同じ次元・12ブロック以内で視線の通るNPCには、通常チャットでも話しかけられます。名前を入れると対象を選びやすくなります。所有者の依頼だけが作業指示を変更します。道具・食料・材料を持たせ、収納先の空きも用意してください。実際のアイテム・耐久・権限に従って作業します。

行き詰まったら、記録を確認移動先・資材・道具・許可・収納先が足りないと作業が保留になることがあります。足りない条件を整えて、範囲や数量を指定し直してください。新規ワールドからドラゴン討伐までの完全自律完走は未検証です。

Right-click an NPC you own. The icons on the right select four menus; hover over an icon for its description.

MenuControls
InventoryNPC slots above, player slots below. Click or Shift-click to transfer items. Set armor, main hand and off hand.
Personality & appearanceEdit personality JSON, model or preset; click 保存・実行 (Save / Run).
Task instructionEnter a task and click 保存・実行. 作業停止 stops work. 追従: ON/OFF toggles following while idle.
JournalRead conversations, instructions and results. 過去の記録 opens older records.

Start with a clear area and quantity

  • “Collect 16 logs and put them in this chest.”
  • “Follow me.” / “Wait here.”
  • “Dig the stone from 100,65,100 to 104,67,104. Leave the floor at Y64.”

You can also use ordinary chat with a visible NPC in the same dimension within 12 blocks. Include its name to address it. Only the owner's requests change its task. Supply tools, food and materials, and leave space in the destination chest. Work uses real items, durability and permissions.

Check the journal when a task is blockedMissing paths, materials, tools, permissions or storage can suspend a task. Resolve the missing condition and give a clearer area or quantity. A fully autonomous run from a new world through defeating the Ender Dragon has not been verified.
06 / MANAGE

呼び戻し・記録・サーバー設定

Recall, records and server settings

  • 呼び戻しの地図：作業台で空の地図を鉄インゴット8個で囲みます。手に持って使用し、自分のNPCを選ぶと近くへ呼び戻します。別次元にも対応し、地図は消費しません。呼び戻すと作業と追従は解除されます。
  • アバターの記録帳：本1冊を鉄インゴット8個で囲みます。手に持って使用すると自分のNPCの保存済み記録を確認できます。
  • アバターアンカー：板材1個を鉄インゴット8個で囲みます。設置して右クリックし、場所IDを保存します。「拠点の倉庫へ行って」のような指示に使えます。近くのチェストはアンカーから8ブロック以内へ置きます。
  • 倒れたとき：既定では所持品を落とし、所有者のリスポーン地点へ復帰して待機します。作業は自動再開しません。

召喚上限と死亡時の扱いは、ホスト側のconfig/bep_3davater_companion-server.tomlに保存します。maxPerPlayer = 3が既定、-1は無制限、0は新規召喚禁止です。dropItemsOnDeath = falseで持ち物を保持して復帰します。

NPCの状態はワールドへ保存されます。会話・作業の履歴はワールド内のbep_3davater_companion/journal/へ記録されます。バックアップはワールド全体と必要なconfigを含めてください。

  • Recall Map: surround an empty map with eight iron ingots. Hold and use it, then choose one of your NPCs to bring it nearby, including from other dimensions. The map is not consumed. Recall clears its task and following state.
  • Avatar Journal: surround a book with eight iron ingots. Hold and use it to read saved records for your NPCs.
  • Avatar Anchor: surround a plank with eight iron ingots. Place it, right-click and save a location ID. Use that name in instructions such as “Go to the base storage.” Keep related chests within eight blocks of the anchor.
  • When defeated: by default the NPC drops its items, returns to the owner's respawn location and waits. Work does not restart automatically.

Host-side limits are in config/bep_3davater_companion-server.toml. The default is maxPerPlayer = 3; -1 means unlimited and 0 prevents new summons. Use dropItemsOnDeath = false to keep items on recovery.

NPC state is saved in the world. Conversation and task history is stored under the world's bep_3davater_companion/journal/. Include the entire world and required config files in backups.

CHECKLIST

接続・動作の確認

Troubleshooting

  • AIモデルタブがない：Companionの導入を確認し、再起動します。
  • 認証できない：ホスト側の接続方法・URL・キー・環境変数を確認します。Codex方式はホスト側のログイン状態も確認します。
  • モデル一覧が出ない：先にローカルサーバーとモデルを起動します。非対応APIではIDを直接入力できます。
  • 保存したのに動かない：ワールド／サーバーを開き直します。リモートサーバーはホスト側を設定してください。
  • NPCを編集できない：自分のNPCであること、サーバーに読み込まれていることを確認します。必要なら呼び戻しの地図を使います。
  • モデルが見えない：表示するクライアントに同じ.avcを配置し、モデルIDを確認して再読込します。
  • No AI Models tab: check that Companion is installed, then restart.
  • Authentication fails: check the host's method, URL, key and environment variable. For Codex, check the host's CLI login.
  • No model list: start your local server and load its model first. Enter the ID manually if the API does not support listing.
  • Saved but no change: reopen the world or restart the server. Configure remote servers on the server host.
  • Cannot edit an NPC: confirm you own it and that it is loaded on the server. Use a Recall Map if necessary.
  • Model is missing: place the same .avc on each displaying client, check the model ID and reload.
