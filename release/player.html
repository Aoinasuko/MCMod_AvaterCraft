Player Modelを追加して、プレイヤーの外見をアバターへ。着用、表情、一人称表示とマルチプレイの設定をまとめました。

Add Player Model to use an avatar as your player appearance. Set up wearing, expressions, first-person arms and multiplayer display.

01 / PREPARE

LoaderとPlayer Modelを導入する

Install Loader and Player Model

bep_3davater_loader-26.3-0.10.0.jarとbep_3davater_player-26.3-0.10.0.jarを、ゲームディレクトリのmods/へ置きます。

アバターはconfig/bep_3davater_loader/avatars/へ配置します。同梱のtortobuを使う場合は独自の変換は不要です。データ配置の手順を見る →

Place bep_3davater_loader-26.3-0.10.0.jar and bep_3davater_player-26.3-0.10.0.jar in the game directory's mods/ folder.

Place your avatar in config/bep_3davater_loader/avatars/. You can use the bundled tortobu without exporting your own model. See the file placement steps →

02 / WEAR

モデルを着る・解除する

Wear or remove a model

  1. ワールド内で@（JIS配列。US配列では[の位置）を押し、Player Modelタブを開きます。
  2. 検索欄からモデルを絞り込み、使いたいモデルをクリックします。
  3. 選択したモデルを着るを押します。選択だけでは反映されません。
  4. 画面を閉じ、視点切り替え（標準はF5）で三人称の表示を確認します。
  5. Minecraft標準の外見へ戻すときは着用を解除を押します。
同じモデルを再出力したとき.avcを置き換えて「再読込」を押し、更新後のモデルを選んで着用し直してください。
  1. In a world, press @ on a JIS keyboard (the [ key position on US keyboards) and open Player Model.
  2. Filter the list with the search box, then click the model you want.
  3. Click 選択したモデルを着る (Wear selected model). Selection alone does not apply it.
  4. Close the screen and switch perspective (default F5) to check the third-person view.
  5. To restore the normal Minecraft appearance, click 着用を解除 (Remove model).
After exporting the same model againReplace the .avc file, click Reload, then select and wear the updated model again.
03 / EXPRESSIONS

表情と一人称表示を調整する

Configure expressions and first-person display

Loaderタブで着用中のモデルを選び、「表情・シェイプキー」を開きます。頭部のシェイプキーを検索し、各スライダーの重みを調整して保存します。「表情キーJSON編集」では任意キーも直接編集できます。

表情キー使われる場面
idle通常の表情
blinkまばたき（初期値2〜4秒ごと）
eat食事・飲み物の使用
hurt被ダメージ

イベントの判定はPlayer Model、キーの表情再生はLoaderが担当します。重なった場合は被ダメージが優先です。設定はモデル別のJSONへ保存され、.avcを直接書き換えません。

一人称の腕・手・指・袖も同じ.avcから読み込みます。腕だけの追加変換は不要です。一人称ではニュートラル姿勢と変換時の既定BlendShapeを使い、袖のPhysBoneやアイテム別の指の握り込みは行いません。

Select the worn model in Loader and open 表情・シェイプキー (Expressions / Shape keys). Search head morphs, adjust their weight sliders and save. Use 表情キーJSON編集 to edit custom keys directly.

Expression keyWhen it is used
idleDefault expression
blinkBlinking (every 2–4 seconds by default)
eatEating and drinking
hurtTaking damage

Player Model detects events and Loader plays the corresponding expression keys. Damage takes priority when events overlap. Settings are stored in a separate per-model JSON file without rewriting the .avc.

First-person arms, hands, fingers and sleeves use the same .avc. No separate arm export is needed. First person uses a neutral pose and exported default BlendShapes; sleeve PhysBones and item-specific finger grips are not simulated.

04 / MULTIPLAYER

他のプレイヤーにも表示する

Show your avatar to other players

  1. サーバーと各クライアントへ、同じ版のLoader＋Player Modelを導入します。
  2. 専用サーバーはonline-mode=trueを使用します。オフライン認証や認証を無効にしたプロキシ構成には対応しません。
  3. 自分のローカルモデルを着用すると、選択中のモデルと表情設定が表示用に自動同期されます。未選択モデルはまとめて送信しません。
  4. 相手側は受信・検証の完了後にアバターを表示します。受信中や上限超過の場合は通常のMinecraftスキンを表示します。

受信データは他人が着用するためのモデル一覧には追加されません。モデル変更・退出・切断時には該当する表示キャッシュを破棄します。同時表示は96ブロック以内の近い4人が対象です。

NPCの追加モデルは各クライアントへ配置プレイヤーの表示用同期をNPCへ流用しません。NPC用の.avcは、表示する各クライアントが用意します。暗号化した表示配信も、モデルごとの利用条件を変更するものではなく、改造クライアントからの抽出を完全に防ぐものでもありません。
  1. Install matching versions of Loader and Player Model on the server and each client.
  2. Dedicated servers must use online-mode=true. Offline authentication and proxy setups that disable backend authentication are not supported.
  3. Wear a local model. The selected model and expression settings are automatically synchronized for display. Unselected models are not uploaded together.
  4. Other clients show the avatar after receiving and validating it. They use the normal Minecraft skin while loading or if resource limits are exceeded.

Received data is not added to another player's wearable model list. Display caches are discarded on model changes, departure or disconnection. Up to four nearby players within 96 blocks use custom display at once.

Place additional NPC models on each clientPlayer display synchronization is not used for NPC models. Each client displaying an NPC needs its .avc. Encrypted display distribution does not change an avatar's license and cannot completely prevent extraction by modified clients.
CHECKLIST

うまく表示されないとき

Troubleshooting

  • Player Modelタブがない：LoaderだけでなくPlayer ModelのJARも導入し、ゲームを再起動します。
  • モデルを選んでも変わらない：Player Modelで「選択したモデルを着る」を押してください。
  • 表情が変わらない：Loaderで対象モデルのシェイプキー名と重みを確認し、保存します。
  • 他人から通常スキンに見える：双方のMOD、サーバーの認証設定、同期状態、モデルの容量を確認します。
  • 服や腕の位置が違う：元のUnityプロジェクトでHumanoid・モーション・素材を確認して再出力します。防具やエリトラの見た目は合成しません。
  • No Player Model tab: install the Player Model JAR as well as Loader, then restart the game.
  • Selection does nothing: click Wear selected model in Player Model.
  • Expressions do not change: check the model's morph names and weights in Loader, then save.
  • Others see a normal skin: check both sides' mods, server authentication, synchronization status and model size.
  • Clothes or arms are misplaced: check Humanoid settings, motions and materials in Unity and export again. Armor and elytra visuals are not combined with the avatar.
