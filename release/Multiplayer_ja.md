# 本人専用アバターのオンライン同期（0.6.0）

選択中のプレイヤーアバターを暗号化してサーバーへ送り、他のプレイヤーは表示専用として受信します。装着を選択できるのはアップロードした本人だけです。ダウンロード・復元・検証が済むまでは、そのプレイヤーの通常のMinecraftスキンを表示します。失敗した場合も通常表示を維持します。

## 導入と使い方

1. サーバーと表示する各クライアントへFrameworkの `avatarcraft-0.6.0.jar` を導入します。NPCも使う場合はNPC用JARも導入します。
2. 専用サーバーでは `online-mode=true` を使用してください。所有者の確認はMinecraftの認証済みUUIDを使います。オフラインモードや、バックエンドのオンライン認証を無効にするプロキシ構成には対応しません。統合サーバーではホスト本人のローカル接続だけを例外として認めます。認証されないLAN参加者への共有は行いません。
3. 自分の `.avc` を `config/avatarcraft/avatars/` に置き、@キーの一覧で選択します。参加時・選択変更時に、そのモデルと現在の表情設定を自動同期します。フォルダ内の未選択モデルをまとめてアップロードすることはありません。
4. 受信側は対応するプレイヤーを自動で表示します。受信ファイルは自分のアバター一覧やNPCのモデル選択には追加されません。
5. 「標準モデル」へ戻すと共有を解除します。モデル変更・所有者の退出・接続終了時には該当キャッシュを破棄します。

サーバーがこの同期機能を持たない場合、従来のローカル表示を継続します。アバターの再変換は不要です。

## 保存と利用制限

- サーバーは受け取ったデータの所有者を接続中のUUIDへ固定します。送信者が他人のUUIDを指定しても採用せず、他人の転送IDを使う装着要求も拒否します。モデルの取得要求は、サーバーが確認した所有者と同じ次元・128ブロック以内に限ります。
- モデルと表情設定はAES-256-GCMで暗号化し、所有者・転送ID・モデルIDを改ざん検出へ結び付けます。
- 表示する相手ごとに、モデル鍵を接続時のRSA公開鍵でOAEP-SHA256暗号化して渡します。通常のサーバー実装は平文モデル・平文モデル鍵を保存しません。
- サーバーの一時領域はワールドの `avatarcraft-private-cache/session-*/`、受信側は `config/avatarcraft/remote-cache/connection-*/` です。いずれも暗号データだけを保存し、通常の `.avc` として書き出しません。
- 復号とモデル検証はメモリ上で行います。受信キャッシュを装着・エクスポートする機能はありません。切断時はモデル鍵と描画状態を破棄します。強制終了した場合は暗号化された一時ファイルが残ることがあり、ゲーム停止中に該当キャッシュを削除できます。
- この機能の対象はプレイヤーアバターです。NPCの追加モデルは引き続き、使用権のあるデータを各クライアントに配置します。表示専用キャッシュをNPCや自分のモデルへ流用する機能はありません。

## リソース上限

| 項目 | 上限・動作 |
| --- | --- |
| アップロード | 元の `.avc` は約63MiB、表情設定は1MiB。暗号化した転送全体は64MiB以下 |
| 分割パケット | 16KiB。連番・サイズ・SHA-256・GCM認証を検証 |
| サーバーの予約済み一時容量 | 合計512MiB、本人ごとに選択中のモデル1件 |
| 受信モデルのZIP展開量 | 128MiB |
| 受信時の画像 | 入力は各辺4096以下・合計約1億3421万画素以下。表示用に約1677万画素・素材の参照量約3355万画素以内へ自動縮小 |
| 受信時の形状 | 20万頂点、64メッシュ、32素材、128サブメッシュ、モーフ変更頂点200万件 |
| 同時表示 | 96ブロック以内でモデルを共有中の近い4人。対象外のプレイヤーは通常スキン |
| 転送待ち | 10分を目安に失効。待機キューと通信量にも上限を設定 |

高解像度モデルは受信側の表示画像だけを予算内に自動縮小し、本人の元ファイルとローカル表示は変更しません。入力上限の超過・不正データ・改ざん・鍵の復元失敗ではモデルを適用しません。アバター一覧の下部に同期状況を表示します。自分では表示できても、受信側の上限を超えるモデルは他プレイヤーには通常スキンで表示されます。

## 利用規約と保護範囲

VRChatのPrivateアバターも本人だけが使用できる設定ですが、このMODが個々のモデルの許諾を変更するものではありません。「他のオンラインサービスへの非公開アップロード」が許可されているか、VRChatだけに限定されていないかをモデルの個別規約で確認してください。[VRChat公式](https://creators.vrchat.com/avatars/creating-your-first-avatar/)、[VN3ライセンスの解説](https://www.vn3.org/terms)

これは正規のクライアント／サーバーにおける使用権の制御です。表示するクライアントには復元したメッシュ・テクスチャが必要なため、改造クライアントやメモリ解析による抽出・再アップロードを完全には防げません。サーバーを鍵交換の中継として信頼する方式であり、悪意のあるサーバーによる鍵の差し替えまで防ぐものでもありません。

## 検証

複数クライアントを模した通信で、暗号化・復元・遅れての参加・本人以外の装着拒否・所有者偽装の拒否・改ざん・退出時の破棄を確認しています。専用GameTestではパケットの往復とサイズ上限を確認します。実際の複数Minecraftクライアントでの同時接続と画面の目視確認は未実施です。
