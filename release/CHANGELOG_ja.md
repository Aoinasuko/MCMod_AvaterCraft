# 0.7.0

リリース日：2026-10-25

- 「アバターアンカー」を追加。鉄インゴット8個で任意の板材1個を囲んで作成し、設置後の右クリック画面から文字列IDを保存。IDを全NPCで共有し、個人の場所記憶8枠を消費せず名前で移動・周囲8ブロックのチェストへの収納／取り出しを指定可能。共有IDの検索ツール`find_anchors`を追加。
- アバターの記録帳のレシピを、中央の本1冊を鉄インゴット8個で囲う形へ変更。

- 持ち場を守る継続監視`guard_post`、時間指定の監視・射撃・食事の`guard`、実際の討伐まで攻撃を続ける`defeat`を追加。継続監視は再計画待ちで中断しない。戦闘経路を通常移動の広域探索へ統合し、照準が帰還移動を妨げる問題を修正。
- 原木を直接燃やさず板材へ加工して精錬する処理、破損時の予備ツールをチェストから優先する処理、ポータル離脱・クールダウン待ち・再進入を改善。
- `plan_next.target`へ文章を入れない計画スキーマと検証を統一し、形式エラー時のみ1回の修復要求を追加。ブロックへのアイテム使用は主手の連続指定とバケツの通常使用にも対応。

- ハーフブロック・階段・積雪などの実当たり判定から歩ける高さ・頭上空間を判定。段差の往復と精密到着を補正し、歩ける段差では不要なジャンプをしないよう改善。
- 移動経路のフェンスゲートを自動で開き、通過後に閉じる処理を追加。所有者の操作権限、元から開いていた状態、他の生物の通過を考慮。段差とゲートの混在を含む専用サーバー試験88件に成功。

- 耕地・土の道の15/16の高さを歩行・落下物回収で扱い、畑に残る収穫物を拾えない問題を修正。初回の地上→地下移動では中間点の実際の足場高を確認。遠方の村との往復・畑の全収穫と植え直し・帰還収納の回帰試験を追加。

- AI向けの在庫一覧を全枠保持し、所持数・装備・耐久を伝えるよう修正。計画セッション切替後に届いた旧応答の例外・誤適用を防止。
- 移動の停滞を新しい経路への進行で判断し、同じ場所の往復で待機が延びる問題を修正。最大512ブロックの長距離移動を128以内の中間点予約で実行し、記録済みの階段による地下からの帰還を改善。
- 精錬の実燃焼時間と必要量を確認し、道具を燃やさず燃料を補充。不足燃料の調達と部分バッチの再開に対応。
- チェストの実容量・操作可能な隣接位置を確認し、部分収納後の満杯やアクセス状況に応じて別の収納先へ切替。移動後の観察を更新。
- 移動目的の計画で歩行・ドア経由を優先する規則を明記し、壁を壊さず迂回する回帰試験を追加。

- 目標達成時の通知を性格・口調に合わせたセリフへ変更。達成・待機の判定はゲーム側で確定し、通知生成は非同期で行う。性格JSONの`completionMessage`で専用文を指定でき、生成失敗時は代替文を一度通知する。

- NPCの失敗対象・検索結果・歩いた帰路を親子タスク間で共有し、同じ失敗の反復と足場資材の再帰調達を抑制。地形・道具・立ち位置が変われば再評価する。
- チェストへの移動を操作可能な隣接位置へ解決し、地下からの帰還では既知の階段・歩行経路を再利用。
- 繰り返し停止した際、外部AIの3〜5手の復旧予約を検証して順に実行し、元の目標の残作業へ戻る。復旧予約は最大2回。
- 検証済みの目標達成を一度通知して待機へ戻り、完了前に生成された古い未確認の発言を破棄。
- 周囲の立て看板・壁看板・吊り看板の表裏を読む`read_signs`を追加。文字・座標・向きを計画に利用し、看板の命令やクリック動作は実行しない。

- 移動・追従・作業経路の目的地を最大128ブロックへ拡張。8方向A*、地形キャッシュ、Tick分割、経路の再利用・変更時の再探索を追加。
- 通常の作業経路は掘削・設置より先に広い歩行迂回を調べる。探索未完了を経路なしと扱ってブロックを置かないよう変更。角や静止したプレイヤー／NPCも考慮。
- 作業経路に障害物の除去・階段状の足場・橋の設置を追加。葉に隠れた原木、高い幹、落下物の回収へ実際の破壊・設置・移動を組み合わせて接近。
- `work_route`を追加し、「ブロックを掘ってこっちに来て」「こっちまで橋を架けて」に対応。所持品・権限・支持・頭上空間・編集予算を確認し、不足資材や道具は既存の実採集・準備処理を使用。
- 高木の上部を見失わないようブロック検索を上下16まで拡張。採集は実所持数で完了を判定し、壊した数だけで完了してしまう経路を修正。落下物の接近精度と、経路変更後の再試行を改善。
- 木製ドアを経路として認識し、移動時に開けて通過後に閉める処理を追加。開いていたドアは開いた状態を維持し、鉄のドアを素手で開けない。
- 原木・板材の総称を資源タグとして扱い、樹種をまたぐ検索・所持数・回収・収納に対応。トウヒなど樹種の指定は維持。
- 日英の命令・状況データを216,000組へ拡充し、曖昧な参照・不足分・収納先・除外指定・確認が必要な依頼を追加。関連例を指示理解AIへ提示。
- 約20MiBのversion 4行動モデルを実学習。5専門家から各候補につき1専門家を実行。
- 未成熟作物やサトウキビ等の根元を収穫対象から除外し、主要作物の採集元を追加。即時破壊ブロックの採掘、消失したドロップへの移動の中断、資源上に乗ったときの退避を修正。

# 0.6.0

リリース日：2026-10-25

- NPCのコンテナ操作でチェスト・ダブルチェスト・樽・シュルカーボックス等の標準の開閉と音を反映。利用者数をバニラへ登録し、複数NPC／プレイヤーとの同時利用や途中停止を処理。
- 通常の遠距離移動・作業先への接近・構造物探索で距離に応じてダッシュし、近距離で歩行へ戻す処理を追加。精密移動や空腹時等は歩行を維持。
- 地面の素材が必要数より少ない場合、存在する分だけを回収して不足分の採集・工作へ戻るよう修正。回収途中でドロップが消えても依存関係を再計算。

- NPC死亡時にバッグ・装備をその場へドロップし、所有者のリスポーン地点へ復帰して待機する処理を追加。ドロップしない設定にも対応し、作業と追従は中断。
- サーバー設定にプレイヤーごとの召喚上限（既定3、-1で無制限）を追加。全次元・未ロード・復帰中のNPCも台帳で管理。
- 「呼び戻しの地図」を追加。空の地図を鉄インゴット8個で囲んで作成し、自分のNPC一覧から別次元のNPCも呼び戻して待機可能。
- 記録帳を、中央の鉄インゴットを本8冊で囲うレシピへ変更。地図と記録帳に専用ドット絵を採用。
- 通常会話の表示範囲を同一次元・半径64へ変更。重要通知はフラグで区別し、距離に関係なく所有者だけへ通知。

- 「協力して」という依頼で、単独なら可能な採掘・収納まで計画段階で停止する問題を改善。保留理由の一度限りの通知と計画・停止のログを追加。
- NPCの指示理解・ローカル行動・発言を分離。日英の依頼は現在のAIで共通タスクに変換。
- 48特徴量、1,051,001パラメータ、約4MiBのversion 3行動モデルを実学習して同梱。装備・採掘・回収・精錬・戦闘・分担待ち等の候補をローカルで評価。
- 同じ所有者のNPCへの担当割当と実物の受け渡し、空の持ち物からの道具・設備準備、バニラかまどでの精錬に対応。
- NPC周囲3×3チャンクの永続Tick読み込み、移動・次元移動・削除時の更新を追加。
- `ai.complexModel`で上位モデルを選択。複雑な依頼の分担と検証済みの進捗を使う段階的計画に対応。
- 照準・狩猟・弓のチャージ・アイテム使用・ブロック／対象への操作・装備・ポータル通過・構造物観察等を追加。全51種の新旧ツールと引数を`NPC_Tools_ja.md`に掲載。
- NPCの模擬プレイヤーが空中扱いで採掘速度が低下する問題、接近・回収・帰還経路の停滞を修正。
- 鉱石の種類をまとめた検索、材料からの道具準備、地上からの階段状の掘り下げ、着地待ちと接近距離の修正を追加。
- NPCごとに最大8件のロケーション記憶をNBTへ保存。離れたアイテムの回収後、出発時に固定したチェストへ帰還・収納。
- 定期発言は30〜60秒、既定45秒に変更。生成待ちでもローカル作業を継続。
- 作業の残数と手順を保存し、切断・再接続時の再開と、回数を制限した再計画に対応。
- 開発者向けの学習・レビュー用データ抽出ツールとガイドを追加。

- プレイヤーアバターの本人専用オンライン同期を追加。所有者をMinecraftの認証済みUUIDに固定し、他人のアバターを装着する要求をサーバーで拒否。
- AES-256-GCMによるモデル・表情設定の暗号化と、受信者別RSA-OAEPによるモデル鍵の転送に対応。平文モデル／平文鍵をキャッシュへ保存しない。
- 受信モデルを表示専用キャッシュに分離。アバター一覧・NPC選択・エクスポートに追加しない。
- ダウンロード・復元・検証が完了するまで、または失敗時は通常のプレイヤースキンを表示。
- 各プレイヤーのモーション・表情・揺れを独立して描画。モデル変更・退出時にキャッシュを破棄。
- 転送・画像・メッシュに上限を設け、クライアント／専用サーバーの処理を分離。高解像度画像は受信側の表示用だけを予算内へ縮小。
