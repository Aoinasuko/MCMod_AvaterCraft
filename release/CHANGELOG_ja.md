# 0.5.1

- ソウルストーンのレシピを `IGI / GGG / IGI` へ変更。鉄インゴット4個と金インゴット5個から1個を作成。
- NPCガイドのレシピ説明を更新。
- アバター形式・素材変換の変更はありません。0.5.0で変換したアバターは再変換せず利用できます。

# 0.5.0

- lilToonの法線マップ2層、MatCap2層、メインテクスチャ2・3層目と合成モードを描画へ反映。
- 色調補正・グラデーション、影の色／強度／境界／ぼかし、リム、発光2層、輪郭幅、ディゾルブの各マスクを追加。
- Unityの法線マップを標準RGBへ復元し、数値マスクと色テクスチャを区別して保存。UV変換とラップ設定も保存。
- 補助画像を余白付きアトラスへまとめ、サンプラ数を抑制。上限に収まらない場合は縮小してログへ通知。
- 配布用説明を整理し、素材の対応範囲と再変換手順を追記。

# 0.4.0

- 召喚アイテムを共通のソウルストーンへ統一。標準モデル「タートブ」（作者：aoi_nasuko）を同梱し、追加モデルは外部読込へ変更。
- GUIでモデルと性格プリセットを独立して選択。ホストの外部性格JSONに対応。
- 主手・副手ラベルを削除し、入力欄と文字数表示を上へ移動。
- 近くのプレイヤーの通常チャットに応答し、所有者の依頼を作業へ反映。複数名・「みんな」への呼びかけに対応。
- NPCの防具・頭装備・エリトラのモデルを非表示にし、装備の性能を保持。
- 不透明・カットアウト・半透明の素材区分、alpha、AlphaMask、深度書込と半透明面のソートを反映。
- 古いモデル別召喚石との互換性はありません。

# 0.3.0

- 提供されたinv.png・info.png・icon.pngでNPC画面を構成。NPCの持ち物を上、プレイヤーの持ち物・ツールバーを下に同時表示。
- アイコンのみの右メニューと、名前・説明を色分けしたツールチップを追加。小さい画面ではGUI全体を縮小。
- 独立した主手・副手への持ち替えスキル、待機時の自動追従と距離に応じたダッシュを追加。
- NPC・プレイヤーへのアイテム受け渡し、チェスト検索・収納・取り出しを追加。満杯時の余りを保存。
- Codex OAuthに加えOpenAI Chat Completions互換・Anthropic Messages互換を追加。LM Studio・Ollamaの接続先を設定可能。
- Mods画面の設定とホスト専用のavatarcraftnpc-ai.tomlへAI設定を統合。APIキーは環境変数またはローカル設定から取得。
- NPCプレビューのモーション・物理状態をワールドの描画から分離。
- NPCの持ち物形式を変更（バッグ36枠、防具4枠、主手・副手）。旧形式からの自動移行は行いません。

# 0.2.0

- 共通アバターAPIとNPC用サブMODを別JARへ分離。
- 性格プリセット、クラフトできる召喚石、任意のアバター指定を追加。
- NPCの36枠の持ち物・防具4枠・オフハンド、性格JSONと作業指示の編集画面を追加。
- Codex CLIのChatGPT OAuth認証と、ゲーム操作の動的ツール呼び出しに対応。
- 観察・移動・追従・ブロック検索・採掘・設置・戦闘・収納・クラフト・食事・発言・待機・停止を追加。
- 近くのNPCとの会話、作業中の1分ごとの発言、永続ログと記録帳を追加。
- 実際の頂点から身長と足元を計算し、スキンメッシュの境界の余白による縮小・浮きを修正。

# 0.1.0

- Minecraft 26.3 / NeoForge向けのアバター描画を追加。
- UnityのHumanoidアバターを `.avc` へ変換するEditorパッケージを追加。
- プレビュー付きアバター選択と、ゲーム内の表情設定に対応。
- 2〜4秒間隔のまばたき、食事、被ダメージのシェイプキーに対応。
- PhysBoneの角度・伸縮制限、カーブ、状態、Collider情報を変換。
- 34動作・39種類の標準モーション、独自AnimationClipの焼込みと動作別割当に対応。
- lilToonの基本設定を近似描画。
- 一人称の腕・手・指・袖をアバターのメッシュへ置換。
- 表情設定画面の重なり、物理状態のプレビューとの干渉、アイテムの倍率・向き等を修正。
