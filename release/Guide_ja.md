# 設定と対応範囲

## モーション

34動作に対して39種類の標準モーションを収録しています。待機、歩行、走行、前後左右の移動、しゃがみ、ジャンプ、落下、着地、水泳、ほふく、はしご、飛行、搭乗、睡眠、攻撃、採掘、食事、飲む、盾、弓、クロスボウ、槍、望遠鏡、角笛、被ダメージ、死亡などの状態へ割り当てます。

Unityの変換画面で「標準モーション」を選択するか、「差し替えClip（任意）」へ独自のAnimationClipを指定します。再生速度は0.1〜4倍、切替時間は0〜2秒です。「確認」でプレビューし、「設定を保存」でプロファイルを保存してから変換します。「編集用 .anim を生成」から39本の編集用クリップを生成できます。

独自Clipは30秒以下を30fpsで焼き込みます。上半身動作と被ダメージの加算を全身動作へ重ねます。Root MotionでMinecraft内のプレイヤー位置を移動させることはありません。旧形式のアバターも読み込めますが、新しいモーション設定を利用するには再変換してください。

## 表情

ゲーム内の「表情設定」から、メッシュ名・シェイプキー名で検索し、通常、まばたき、食事、被ダメージの重みを設定します。保存するとアバターとは別のJSONへ記録します。キャンセルやEscでは編集中の変更を破棄します。

まばたきは初期値で2〜4秒のランダム間隔です。優先順位は被ダメージ、食事、まばたき、通常です。対応する形状があれば、閉眼の `blink` と食事の口の `vrc.v_aa` を自動で割り当てます。名前が異なるアバターは手動で調整してください。

## PhysBone

Angle / Hinge / Polarの角度制限、制限軸、Max Stretch / Max Squish、Stretch Motion、各カーブ、有効状態、複数子・入れ子の設定、球・カプセル等のCollider情報を変換します。長さは基準長× `[1-Max Squish, 1+Max Stretch]` の範囲へ制限します。

Unityの設定を変更したら `.avc` を再変換してください。VRChatの非公開ソルバーと動作が完全一致するものではありません。掴み・ポージングの許可値は保存しますが、他プレイヤーによる掴み操作は実装していません。

## 描画と一人称

ローカル／他プレイヤーの三人称、一人称の腕・手・指・袖、GUIの3Dプレビューに対応します。一人称は左右の腕だけを抽出してMinecraftの攻撃・持ち替え・地図の動きへ合わせます。一人称ではニュートラル姿勢と変換時のデフォルトBlendShapeを利用し、袖のPhysBoneやアイテム別の指の握り込みは行いません。

lilToonは基本色、UV、透過、陰影の境界、リム光、発光、アウトラインを近似します。Unityのシェーダーを直接実行しているものではありません。不透明・カットアウト・半透明、色のalpha、AlphaMaskの置換・乗算・加算・減算、深度書込を反映します。重なり合う半透明面や素材間の順序はUnityと完全には一致しません。新しい素材情報は更新したツールで再変換してください。法線2層、MatCap2層、メイン2・3層目、色調補正と各種マスクに対応します。設定別の対応・近似・制限と再変換手順は `LilToon_ja.md` を参照してください。

Animator FX、VRChat Expression Menu、Minecraft防具・エリトラの外観、足裏IKや地形への足接地補正は未対応です。

プレイヤーの暗号化同期は `Multiplayer_ja.md` を参照してください。これは本人専用の表示配信で、NPC外見の自動配布とは別の機能です。

## 検証した範囲

Minecraft 26.3、NeoForge 26.3.0.95、Java 25、Unity 2022.3.22f1で確認しました。外部アバターを含む自動検証で、スキニング、表情、アーカイブ検証、モーション、物理制限、一人称の左右分離・倍率・互換性を確認しています。

ゲームでUI、主要な移動とアイテム動作、PhysBone制限、一人称の空手・攻撃・左右の地図・食事表示を確認しました。全アバターの体格、全モーション、全装備、全利き手の組合せを実機で網羅したものではありません。体格や衣装に応じてUnity側のモーションを調整してください。

リポジトリ単体でのテストでは外部アバターが不要な検証を実行し、アバターを必要とする7件は未指定時にスキップします。任意の検証用 `.avc` を `AVATARCRAFT_TEST_AVATAR` 環境変数で指定すると統合テストも実行します。
