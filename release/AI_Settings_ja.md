# AIモデルタブ

Companionを導入すると、@キーで開くB.E.P 3DAvaterシリーズ設定に「AIモデル」タブが追加されます。接続方式、APIキー、通常モデル、複雑な計画用モデルをゲーム内から設定できます。

## 接続と保存

1. 「AIモデル」タブを開き、「接続方法」をクリックして方式を選びます。
2. 必要に応じてAIの有効／無効を切り替えます。
3. API方式では接続先URLとAPIキーを入力します。キーは伏せ字で表示します。環境変数を使う場合はその名前を指定します。環境変数に値があると、入力したキーより優先されます。
4. 「通常モデルを一覧から選択」を押すと、入力中の接続設定でモデル一覧を取得します。検索してモデルをクリックすると設定画面へ戻ります。モデルIDの直接入力もできます。
5. 必要なら「複雑な計画用モデル」も指定します。空欄なら通常モデルを使います。
6. 「設定を保存」を押し、ワールドを開き直してください。保存せずキャンセルすると変更は反映しません。

一覧にはNPCの会話・ツール呼び出しに対応していないモデルが含まれる場合があります。利用する接続先で、関数ツール呼び出しとJSON出力に対応するモデルを選んでください。モデル一覧を提供しない互換APIでも、モデルIDを直接入力して保存できます。

## 選べる接続方式

| 方式 | 初期URL | 認証・モデル |
| --- | --- | --- |
| Codex / ChatGPT OAuth | CLIが管理 | ホスト環境でCodexにログイン。APIキー入力は不要。通常モデルが空欄ならCodexの既定を使用 |
| OpenAI API | `https://api.openai.com/v1` | APIキー、モデルIDを指定 |
| Anthropic API | `https://api.anthropic.com/v1` | APIキー、モデルIDを指定 |
| LM Studio | `http://localhost:1234/v1` | ローカルサーバーを起動。認証不要ならキーは空欄 |
| Ollama | `http://localhost:11434/v1` | ローカルサーバーを起動。認証不要ならキーは空欄 |
| OpenAI互換 API / URL指定 | 編集可能 | 対応サーバーのURL、必要なキー、モデルIDを指定 |

接続方法を別の方式へ切り替えると、前の方式のAPIキーやモデルIDはコピーしません。同じ画面内で元の方式へ戻ると、その方式の編集中の内容へ戻れます。

## ホストと保存先

接続設定はこのMinecraftを起動したPCの `config/bep_3davater_companion-ai.toml` に保存します。キーはこのローカルファイルでは平文になります。実際のキーを含む設定ファイルを配布しないでください。環境変数名だけを設定する方法も使えます。

シングルプレイではこのPCがNPCのAIを実行します。専用サーバーへ接続中にこのタブを編集しても、専用サーバーのAI設定は変わりません。専用サーバーで動くNPCは、サーバーホスト側の同じ設定ファイルを使用します。APIキーと接続設定をNPCの性格JSON・ワールド内のNPCデータ・マルチプレイ用パケットへ含めません。

モデル一覧の取得は「一覧から選択」を押した場合にだけ行います。取得先への認証に入力キーまたは環境変数のキーを使います。モデル一覧の取得では会話・作業指示を送信せず、保存だけでは接続テストや推論を行いません。Codex OAuthの認証情報は引き続きCLIが管理します。
