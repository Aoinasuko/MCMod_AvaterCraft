01 / UNITY PROJECT

VRChatプロジェクトへUnityPackageを導入する

Install the UnityPackage in your VRChat project

普段アバターを編集しているUnityプロジェクトを使います。変換するアバターのルートに、有効なHumanoid Animatorが必要です。確認環境はUnity 2022.3.22f1です。

  1. 配布ZIPを展開し、Unity/BEP-3DAvater-Exporter-0.10.0.unitypackageを確認します。
  2. アバターのUnityプロジェクトを開き、SDK・シェーダーなどのコンパイルが終わるまで待ちます。Modular Avatarを使うアバターでは、そのプロジェクトにModular AvatarとNDMFも必要です。
  3. Assets > Import Package > Custom Package…から上記のUnityPackageを選択します。
  4. インポート画面でファイルを選択したままImportを押します。ツールはAssets/BEP3DAvaterExporter/へ入ります。
  5. コンパイル後、メニューにTools > B.E.P 3DAvater Exporterが表示されることを確認します。
既に導入済みのときUPM版（Package Managerのローカル／tarball）とUnityPackage版を同時に入れないでください。UPM版を使っていた場合は、Package Managerからその登録を外してからUnityPackage版を導入します。アバターや保存したモーションプロファイルは残してください。
Newtonsoft.Jsonのエラーが出る場合・UPM形式で導入する場合

UnityPackageは依存パッケージを自動導入しません。Newtonsoft.Jsonが未導入の場合は、Window > Package Manager > + > Add package by name…でcom.unity.nuget.newtonsoft-json、バージョン3.2.1を追加します。インターネット接続が必要になる場合があります。

UPM版を使う場合はUnityPackageを導入せず、Add package from tarball…でUnity/dev.avatarcraft.exporter-0.10.0.tgzを選びます。UPM版は同じツールと依存パッケージ指定を含みます。

Use the Unity project where you normally edit your avatar. The avatar root must have a valid Humanoid Animator. The exporter was checked with Unity 2022.3.22f1.

  1. Extract the release ZIP and locate Unity/BEP-3DAvater-Exporter-0.10.0.unitypackage.
  2. Open the avatar's Unity project and wait for its SDK and shaders to compile. If the avatar uses Modular Avatar, install Modular Avatar and NDMF in that project too.
  3. Choose Assets > Import Package > Custom Package… and select the UnityPackage.
  4. Keep the package files selected and click Import. The tool is installed under Assets/BEP3DAvaterExporter/.
  5. After compilation, check for Tools > B.E.P 3DAvater Exporter in the menu.
Updating an existing installationUse one installation method per project. If you used the UPM version through Package Manager, remove its registration before importing the UnityPackage. Keep your avatar and saved motion profiles.
Newtonsoft.Json errors / installing the UPM version

The UnityPackage does not install package dependencies automatically. If Newtonsoft.Json is missing, open Window > Package Manager > + > Add package by name… and add com.unity.nuget.newtonsoft-json version 3.2.1. This may require an internet connection.

For UPM installation, skip the UnityPackage and use Add package from tarball… to select Unity/dev.avatarcraft.exporter-0.10.0.tgz. It contains the same tool and declares the dependency.

02 / EXPORTER

ツールを使って、.avcへ変換する

Export your avatar as an .avc file

  1. Hierarchyでアバターのルートを選び、Tools > B.E.P 3DAvater Exporter > Avatar export and motionsを開きます。
  2. 上部のLanguage / 言語から日本語またはEnglishを選び、アバターのルート欄を確認します。ルートをドラッグして指定することもできます。
  3. 動作ごとの「標準モーション」を選びます。34動作・39本の標準Clipを収録しています。「差し替えClip（任意）」には独自のAnimationClipを指定できます。
  4. 「確認」でプレビューし、再生速度（0.1〜4倍）と切替時間（0〜2秒）を調整します。「編集用 .anim を生成」は、編集用のClipをAssets以下に作成します。
  5. 設定を保存でモーションプロファイルをAssets以下へ保存します。必要なアバターでは、複製上へのModular Avatar / NDMF適用を有効にします。
  6. この設定で .avc を変換を押し、保存先とファイル名を選びます。結果と警告を確認し、できた.avcを次の手順でゲームへ配置します。
Unityで設定を変えたら、再変換衣装・素材・PhysBone・モーションの変更は、.avcを再出力して反映します。元のシーンアバターは保持されます。NDMFによる一時アセットがプロジェクト内に残る場合があります。
変換で再現する範囲

メッシュ、テクスチャ、Humanoid参照、BlendShape、対応するlilToon素材、モーション、PhysBone情報を変換します。UnityのシェーダーとVRChatの物理を近似するため、見た目や揺れは完全には一致しません。Animator FX、VRChat Expression Menu、実行時スクリプト、他者によるPhysBoneの掴みは動きません。Minecraftの防具・エリトラの外観もアバターへ合成しません。

  1. Select the avatar root in the Hierarchy. Open Tools > B.E.P 3DAvater Exporter > Avatar export and motions.
  2. Choose 日本語 or English under Language / 言語. Check Avatar root; you can drag the root into this field.
  3. Choose a Built-in motion for each action. The library includes 34 actions and 39 clips. Assign your own AnimationClip to Custom clip (optional) when needed.
  4. Use Preview to check the result. Set playback speed (0.1–4×) and blend duration (0–2 seconds). Generate editable .anim clips creates clips in an Assets subfolder.
  5. Click Save profile to save a motion profile in Assets. Enable Apply Modular Avatar / NDMF to an isolated clone if your avatar requires it.
  6. Click Export .avc with this profile, select the destination and filename, then check the result and warnings. Place the exported .avc in Minecraft as described next.
Changed something in Unity? Export again.Changes to clothing, materials, PhysBones and motions require a new .avc export. The original scene avatar is preserved. NDMF may leave generated temporary assets in the project.
What conversion supports

The exporter includes meshes, textures, Humanoid references, BlendShapes, supported lilToon material settings, motions and PhysBone data. Shader and physics behavior is approximated, so it may differ from Unity or VRChat. Animator FX, VRChat Expression Menus, runtime scripts and PhysBone grabbing by other users are not executed. Minecraft armor and elytra visuals are not combined with the avatar.

03 / MINECRAFT FILES

MOD環境へ、変換したデータを置く

Place the exported data in your modded game

Minecraft Java Edition 26.3 / NeoForge 26.3.0.95 / Java 25の環境を使います。配置先は、実際に起動するランチャープロファイルのゲームディレクトリです。

  1. ゲームを終了し、配布物のMinecraft/mods/から必要なJARをゲームディレクトリのmods/へコピーします。
  2. 変換した.avcをconfig/bep_3davater_loader/avatars/へ置きます。フォルダがなければ作成します。.avcは展開しません。
  3. ゲームを起動します。起動中にデータを追加・更新した場合は、Loaderタブで「再読込」を押してください。

Use Minecraft Java Edition 26.3 / NeoForge 26.3.0.95 / Java 25. Place files in the game directory used by the launcher profile you actually start.

  1. Close the game. Copy the required JARs from the release's Minecraft/mods/ into the game directory's mods/ folder.
  2. Place the exported .avc in config/bep_3davater_loader/avatars/. Create the folder if needed. Do not extract the .avc archive.
  3. Start the game. If you add or update files while it is running, click 再読込 (Reload) in Loader.

04 / IN-GAME SETTINGS

@キーから、ゲーム内で設定する

Open the in-game series settings

ワールド内で@（JIS配列）、またはUS配列の[に相当する位置のキーを押します。キーはMinecraftの操作設定で変更できます。導入したMODに合わせてタブが追加されます。

LoaderPlayer ModelCompanionAIモデル
  • Loader：モデルを検索・選択します。「表情・シェイプキー」は頭部をまとめた検索＋縦スクロール式です。表示を「すべて」へ変えると他のキーも表示します。
  • 表情キーJSON編集：通常・まばたき・食事・被ダメージ、任意の表情キーを編集し、検証して保存します。設定はconfig/bep_3davater_loader/expressions/<avatar-id>.jsonへ保存されます。
  • Player Model：モデルを選んで「選択したモデルを着る」を押します。
  • Companion：召喚済みの自分のNPCをクリックして、モデルと性格を変更します。
  • AIモデル：Companion導入時に表示されます。接続方式・APIキー・モデルを設定し、保存してからワールドを開き直します。
一覧で選ぶだけでは、プレイヤーの外見は変わりませんプレイヤーへの着用はPlayer Modelタブから行います。NPCへの適用はCompanionタブから保存してください。詳しい手順は下の各ページへ進んでください。

In a world, press @ on a JIS keyboard, or the physical key corresponding to [ on a US keyboard. Change the binding in Minecraft's controls if necessary. Installed mods add their own tabs.

LoaderPlayer ModelCompanionAIモデル
  • Loader: search and select models. 表情・シェイプキー (Expressions / Shape keys) groups head morphs and supports search and continuous scrolling. Use the “all” filter to show other morphs.
  • 表情キーJSON編集 (Expression-key JSON): edit idle, blink, eating, damage and custom keys; validate and save. Overrides are stored in config/bep_3davater_loader/expressions/<avatar-id>.json.
  • Player Model: select a model and click 選択したモデルを着る (Wear selected model).
  • Companion: click one of your summoned NPCs to change its model and personality.
  • AIモデル (AI Models): appears with Companion. Choose the connection method, API key and model. Save, then reopen the world.
Selecting a model in Loader does not equip itWear your avatar through Player Model. Save NPC changes through Companion. Continue to the relevant page below for detailed steps. English explanations retain the Japanese button labels where the game UI uses them.

困ったとき・クレジット

Troubleshooting & credits

変換メニューが出ない / コンパイルエラー

Unity Consoleの最初のエラーを確認してください。Newtonsoft.Jsonなどの依存関係、アバターに必要なSDK・シェーダー、UPM版とUnityPackage版の重複を確認します。

モデルが一覧に出ない / タブが足りない

使用中のゲームディレクトリ、.avcの拡張子、avatars直下への配置を確認して「再読込」します。Player ModelとCompanionのタブは、それぞれのMODを導入したときだけ表示されます。モデルの読込エラーはlogs/latest.logを確認してください。

衣装・表情・揺れが違う

必要なSDK・NDMF等を含む元プロジェクトで再変換します。表情名が異なる場合はLoaderでキーを手動調整します。VRChatと同一の描画・物理・Expression Menu動作を保証するものではありません。

クレジット：同梱モデル：tortobu / 作者：aoi_nasuko。Companionの同梱性格は一人称「ぼく」でおっとりした性格です。

No export menu / compilation errors

Check the first error in the Unity Console. Verify Newtonsoft.Json, required avatar SDKs and shaders, and that you have not installed both the UPM and UnityPackage versions.

A model or tab is missing

Check the active game directory, .avc extension and placement directly inside avatars, then click Reload. Player Model and Companion tabs appear only when their respective mods are installed. Check logs/latest.log for model-loading errors.

Clothing, expressions or physics look different

Re-export from the original project with its required SDK and NDMF packages. Adjust expression keys in Loader if morph names differ. Rendering, physics and Expression Menu behavior do not exactly match VRChat.
