# lilToon素材の対応範囲（0.6.0）

Unity側の素材設定を専用ファイルへ保存し、Minecraft用のGLSLで近似描画します。Unityのシェーダーそのものを実行する方式ではなく、照明やカメラの違いによる差があります。

## 更新と再変換

1. Loaderを26.3-0.10.0へ更新し、使用するPlayer Model・Companionも同じ版へ合わせます。
2. UnityのAvatarCraft変換パッケージも0.6.0へ更新します。
3. アバターを再変換して `.avc` を置き換え、ゲーム内の一覧を再読み込みします。以前のファイルでは追加画像が保存されていない場合があります。

0.5.0以降のツールで変換済みなら、0.6.0のオンライン同期のための再変換は不要です。

標準のtortobuは新しい変換処理で同梱しています。既に `config/bep_3davater_loader/avatars/tortobu.avc` がある場合は自動で上書きしません。標準データへ更新したい場合は、そのファイルを別の場所へ保管してMinecraftを起動してください。

## 反映する設定

| 機能 | 対応する設定 |
| --- | --- |
| 法線マップ | 1・2層目、有効状態、個別の強度、2層目の強度マスク。Unityの法線圧縮をRGBへ復元して保存 |
| MatCap | 1・2層目、有効状態、色、強度、通常／加算／スクリーン／乗算、RGB合成マスク、個別法線と強度、元色の影響、照明・影・裏面・透明度への追従 |
| メイン2・3層目 | 有効状態、テクスチャ、色、通常／加算／スクリーン／乗算、合成マスク、alphaの置換／乗算／加算／減算、照明の影響、UV変換・回転・スクロール、デカールの範囲クリップ、面のカリング、UV左右の片側指定 |
| 色調補正 | HSVG、色調補正マスク、グラデーションテクスチャと強度 |
| 影 | 1〜3段目の色テクスチャ、強度マスク、RGBの境界・ぼかしマスク。Minecraftの照明に合わせた近似 |
| リム | 色テクスチャ、色とalpha、境界・ぼかし、合成モードと照明の影響 |
| 発光 | 1・2層目、色・強度・元色の影響、RGB合成マスク、合成モード、UV変換・スクロール。表面の透過を共有 |
| 輪郭 | 色・テクスチャ、幅、幅マスク。幅マスクは頂点単位で適用 |
| 透明度 | 不透明／カットアウト／半透明、色のalpha、AlphaMaskの置換／乗算／加算／減算、深度書込 |
| ディゾルブ | 全体とメイン2・3層目のマスク、ノイズマスクと強度、閾値・境界色。UV上の線形・円形、モデル座標の近似にも対応 |

数値マスクと法線は色テクスチャと区別して変換します。補助画像のUV倍率・移動とRepeat／Clamp／Mirror／MirrorOnceを反映します。

## 差が残る設定

- メッシュのUV0とMatCap座標を使います。UV1〜3を指定した素材はUV0へフォールバックし、変換結果へ警告を出します。
- MatCapのカメラ方向・透視補正は近似です。VR両眼補正、カメラロール補正、UV1との合成、指定LODのぼかしは再現しません。
- デカールのコピー・ミラーコピー、アニメーションアトラス、MSDF、距離フェード、AudioLink、頂点変形用マスク、視差・反射・異方性など、この表にない機能は描画へ反映しません。
- ディゾルブの座標とノイズは静的な設定を使います。UnityのAnimatorによる値の変更や、ノイズ自体のスクロールは実行しません。モデル座標の形状・スケールはUnityと異なる場合があります。
- メイン／発光のスクロールはゲーム時間を使い、Minecraftの20分周期で巻き戻ります。複雑なブレンドや照明の順番はUnityと完全には一致しません。
- 半透明の自己交差や素材間の重なり順、UnityのHDR・色空間・ポストエフェクトによる見た目は完全には一致しません。

## テクスチャと検証

補助テクスチャは素材ごとに余白付きアトラスへまとめ、GPUで使うテクスチャ数を抑えます。アトラスは最大4096×4096で、収まらない場合だけ補助画像を縮小してログへ通知します。補助画像のサンプリングは線形補間で、個別のミップマップ・異方性設定は使いません。

自動検証では合成式・アトラスの余白／alpha保持／縮小・既定値を確認します。`tools/validate_surface_gpu.py` は実際のGLSLとMinecraftのシェーダー定義を、ゲームから独立した非表示のOpenGLコンテキストでコンパイルし、法線・MatCap・各層・マスク・透明度の描画ピクセルを検証します。すべての素材設定・アバターを網羅したものではありません。
